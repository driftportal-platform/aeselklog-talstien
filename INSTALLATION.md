# Installation af ÆselKlog

Aktuel opdatering: v0.9.76 – samlede indstillinger i Talkort.

1. Pak opdateringen ud i projektmappen, erstat filerne og bevar undermapper. Bevar audio, music og assets.
2. Kør `npm.cmd test`: 58/58 skal bestå. Commit og Push origin i GitHub Desktop. Bevar `.github/workflows/test.yml`.
3. Kun GitHub skal opdateres. Cloudflare er uændret.
4. Genåbn efter GitHub Pages er færdig, og kontrollér versionsmærket 0.9.76.

## Talkort
Kortet og Forrige/Læs igen/Næste står først. Nedenunder ligger fire menuer: Talområde, sprog og stemme (inklusive pause), Automatisk oplæsning, Tæl op eller ned og Øv min udtale. Åbn og luk dem efter behov.

Start Auto eller en tælling og luk menuen: Stop og status skal stadig være synlige. Valg bevares ved sammenfoldning. Menuforløb er browserprøvet ved mobil/pc-størrelser med simuleret lyd. Lydrettelsen fra v0.9.74 er med og skal fortsat kontrolleres på den berørte telefon.
