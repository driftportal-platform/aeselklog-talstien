# Installation af ÆselKlog

Aktuel opdatering: v0.9.81 – ens ikonstørrelse i spilmenuen.

1. Pak opdateringen ud i projektmappen og erstat filerne. Bevar undermapper, audio, music og assets.
2. Commit og Push origin i GitHub Desktop. Bevar `.github/workflows/test.yml`.
3. Kun GitHub opdateres. Cloudflare/Worker v0.9.78 er uændret.
4. Når GitHub Pages er færdig: genåbn appen og kontrollér versionsmærket 0.9.81. TorskeKlog og 500 skal have samme ikonstørrelse som de øvrige spil, uden overlap med teksten.

Valideret: 63/63 Node-tests og browserprøver af ikonstørrelser og spilmenu på mobil/tablet/pc. Ingen fysisk telefonprøve eller publicering herfra.
